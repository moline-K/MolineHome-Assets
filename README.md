# MolineHome-Assets

MolineHome branding assets and application themes derived from the brand CSS and logo palette.

## Themes

The repo now includes:

- `themes/shared` for the canonical MolineHome palette and design tokens
- `themes/vscode` for installable VS Code light and dark themes
- `themes/obsidian/MolineHome` for an Obsidian community theme
- `themes/codex` for ChatGPT Codex light/dark/accent guidance based on the same palette
